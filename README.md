# InsightAI 🤖📊

InsightAI is a Python-based data analysis application designed to make
CSV data analysis simple and interactive.

The application allows users to upload a CSV dataset, explore the data,
view important statistics, and generate interactive visualizations.

## 🚀 Features

- 📁 Upload CSV datasets
- 🔍 Explore and understand data
- 📊 Generate interactive visualizations
- 📈 View statistical summaries
- 🧹 Basic data analysis and preprocessing
- 💡 Generate useful data insights
- 🖥️ Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Pandas
- Plotly
- Streamlit
